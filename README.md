# Код Жолы 🤖

Python-ды **көзбен көріп** үйрену платформасы. Оқушы код жазады, ал ол қалай жұмыс істейтінін робот пен түсті қораптар арқылы тірі анимацияда көреді. Қазақ тілінде, браузерде, ештеңе орнатпай жұмыс істейді.

## Мүмкіндіктері

- **Нағыз Python.** Код браузердің ішінде [Pyodide](https://pyodide.org) арқылы орындалады.
- **Қадаммен орындау.** ▶ толық ойнату, ⏭ бір қадам алға, ⏮ бір қадам артқа, слайдермен кез келген қадамға өту.
- **Жад көрінісі.** Әр айнымалы түсті қорап болып көрінеді, мәні өзгергенде қорап «секіріп» шығады. Тізімдер қатар тұрған қораптар.
- **Робот алаңы.** `alga()`, `onga()`, `solga()`, `zhinau()` командаларымен роботты жүргізіп, жұлдыз жинайды.
- **Қазақша қате түсіндірмелері.** Мысалы, `':' белгісі жетіспейді`, `шегініс дұрыс емес`.
- **Жұлдыз жүйесі.** Код қысқа болған сайын жұлдыз көп (1–3 ⭐). Прогресс браузерде сақталады.

## Тапсырмалар (қазір 18)

| Тақырып | Тапсырмалар |
|---|---|
| 1 · Айнымалылар | Екі қорап, Сәлемдесу |
| 2 · Робот командалары | Бірінші қадам, Бұрылыс, Екі жұлдыз |
| 3 · `for` циклі | Жолдағы жұлдыздар, Шаршы, Баспалдақ |
| 4 · `if / else` | Жұп па, тақ па?, Жұлдыз бар ма?, Қабырғаға тіресе бұрыл |
| 5 · `while` | Қабырғаға дейін, Екі қабырға, Санау |
| 6 · Функциялар | Өз командаң, Қосу функциясы |
| 7 · Тізімдер | Жеміс тізімі, Тізімнің қосындысы |

Робот командалары: `alga(n)`, `onga()`, `solga()`, `zhinau()`, сенсорлар: `zhuldyz_bar()`, `aldy_bos()`.

## Vercel-ге жариялау

1. [vercel.com](https://vercel.com) сайтына GitHub аккаунтымен кір.
2. **Add New → Project** басып, `kod-zholy` репозиторийін таңда.
3. Framework Preset: **Other**. Build Command және Output Directory бос қалсын.
4. **Deploy** бас. Бір минуттан кейін сайт дайын.

Бұл статикалық сайт, сондықтан қосымша баптау, `.env` не сервер қажет емес.

## Жергілікті іске қосу

```bash
python3 -m http.server 8000
```

Сосын браузерде `http://localhost:8000` аш. (`index.html`-ды тікелей ашсаң, `py/runner.py` жүктелмейді, сондықтан міндетті түрде сервер керек.)

## Құрылымы

```
index.html        бет
style.css         дизайн
js/levels.js      тапсырмалар, жұлдыз санау, тексеру
js/app.js         интерфейс, анимация, прогресс
py/runner.py      Python орындаушы: әр қадамды жазып алады (sys.settrace)
```

## Жаңа тапсырма қосу

`js/levels.js` ішіндегі `KZ.levels` тізіміне объект қос:

```js
{
  id: "3.4", topic: "3 · for циклі: ...", title: "Атауы",
  task: "<p>Тапсырма мәтіні (HTML)</p>",
  hint: "Кеңес", starter: "# бастапқы код\n",
  solution: "эталон шешім", par: 3,        // par: 3 ⭐ үшін ең көп жол саны
  robot: { cols: 5, rows: 5, start: { x: 0, y: 0, d: 1 }, stars: [[4, 0]] },  // d: 0↑ 1→ 2↓ 3←
  check: { collectAll: true, requireFor: true },
}
```

`check` ішінде мыналарды қолдануға болады: `output` (print нәтижесі), `vars` (соңғы айнымалы мәндері), `collectAll`, `requireFor`, `requireWhile`, `requireIf`, `requireDef`, `requireList`, немесе өз функцияңды `fn(res)` ретінде жаз. Роботта `strict: true` қойсаң, жұлдыз жоқ жерде `zhinau()` қате береді (`if` үйрету үшін).
