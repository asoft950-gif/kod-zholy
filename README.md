# Ботакод

Кодтауды **көзбен көріп** үйрену платформасы: Python, HTML, CSS, JavaScript. Қазақ тілінде, браузерде, ештеңе орнатпай жұмыс істейді.

| 🐍 Python | дайын (7 тақырып, 18 тапсырма, 3 қосымша, 7 лекция, анықтамалық) | робот + қораптар + қадамдап орындау |
| 🌐 HTML | дайын (7 тақырып, 14 тапсырма, 3 қосымша, 7 лекция, анықтамалық) | тірі алдын ала көру, құрылым ағашы |
| 🎨 CSS | дайын (7 тақырып, 14 тапсырма, 3 қосымша, 7 лекция, анықтамалық) | тірі алдын ала көру, қорап моделі |
| ⚡ JavaScript | дайын (7 тақырып, 15 тапсырма, 3 қосымша, 7 лекция, анықтамалық) | қадамдап орындау, қораптар, нағыз бет (DOM) |

JavaScript кодын Python-дағыдай қадамдап көруге болады: оң жақта айнымалылар, экран және (DOM тапсырмаларында) бет көрінеді. Соңғы қадамда бет нағыз жұмыс істейді, батырмаларды басуға болады.

Әр курстың төрт бөлімі бар: 📖 Лекциялар, 🎮 Тапсырмалар, 🏆 Қосымша, 📚 Анықтамалық. Python курсында қосымша 🧪 Еркін алаң бар.

## Мүмкіндіктері

- **Тақырыптар кезекпен ашылады** (Coursera сияқты): алдыңғы тақырыптың барлық тапсырмасы өтілмейінше (кемінде 1 ⭐), келесі тақырып пен оның лекциялары құлыптаулы. Қосымша тапсырмалар мен Еркін алаң әрқашан ашық. Мұғалім курс бетіндегі «Барлық тақырыпты ашу» батырмасымен құлыптарды өшіре алады.
- **Нағыз Python.** Код браузердің ішінде [Pyodide](https://pyodide.org) арқылы орындалады (тек Python алаңы ашылғанда жүктеледі).
- **Қадаммен орындау.** ▶ толық ойнату, ⏭ бір қадам алға, ⏮ бір қадам артқа, слайдермен кез келген қадамға өту.
- **Жад көрінісі.** Әр айнымалы түсті қорап болып көрінеді. Тізімдер қатар тұрған қораптар.
- **Робот алаңы.** `alga()`, `onga()`, `solga()`, `zhinau()` командалары, `zhuldyz_bar()`, `aldy_bos()` сенсорлары.
- **Қазақша қате түсіндірмелері.**
- **Жұлдыз жүйесі.** Код қысқа болған сайын жұлдыз көп (1–3 ⭐). Прогресс браузерде сақталады.
- **Серия 🔥, күннің тапсырмасы 📅, жетістіктер 🏆.** Күн сайын кемі бір тапсырма шешсең (не лекция оқысаң), серия өседі. Басты бетте «Күннің тапсырмасы» шығады (соңғы оқыған курстан, әлі өтілмеген деңгей). `#/achievements` бетінде 5 апталық күнтізбе мен жетістіктер тізімі. Код: `js/streak.js`. Аккаунтпен кірсең, белсенді күндер бұлтқа да сақталады (`activity_days`).

## Мұғалім тапсырмалары

Мұғалім сынып карточкасынан «＋ Жаңа тапсырма» басып, шарт, бастапқы код, өз шешімін жазады (Python не JavaScript). «Шешімді іске қосу» күтілетін нәтижені мен «ең көбі неше жол» шамасын өзі толтырады. Оқушы тапсырманы кабинетінен (`#/task/<id>`) ашып, кодын жазады; экранға шыққан мәтін күтілгенге дәл келсе, жұлдыз алады (код қысқа болса, 3 ⭐). Күтілетін жауап оқушыға берілмейді, тек оның SHA-256 хэші. Мұғалім сынып ішінде кім орындағанын көреді. Код: `js/assign.js`, `js/cabinet.js`, `play.js` (`openAssignment`).

## Жаңа тапсырма қосу

`js/courses/python.js` ішіндегі `levels` тізіміне объект қос (қосымша тапсырма үшін `python-content.js` ішіндегі `bonus`):

```js
{
  id: "3.4", title: "Атауы",             // id-дің бірінші саны тақырыптың нөмірі
  task: "<p>Тапсырма мәтіні (HTML)</p>",
  hint: "Кеңес", starter: "# бастапқы код\n",
  solution: "эталон шешім", par: 3,        // par: 3 ⭐ үшін ең көп жол саны
  robot: { cols: 5, rows: 5, start: { x: 0, y: 0, d: 1 }, stars: [[4, 0]] },  // d: 0↑ 1→ 2↓ 3←
  check: { collectAll: true, requireFor: true },
}
```

`check` ішінде: `output`, `vars`, `collectAll`, `requireFor`, `requireWhile`, `requireIf`, `requireDef`, `requireList`, `forbid`, немесе өз функцияңды `fn(res)` ретінде жаз. Роботта `strict: true` қойсаң, жұлдыз жоқ жерде `zhinau()` қате береді; `walls: [[x, y], …]` қабырға қосады.

Лекция блоктарының түрлері: `h`, `p`, `list`, `code`, `try` (кодты Еркін алаңда ашады), `tip`, `warn`, `boxes`, `arr`, `board`.

## HTML/CSS тапсырмасын қосу

`js/courses/html-content.js` не `css-content.js` ішіндегі `levels` тізіміне қос. `kind: "html"` — оқушы HTML жазады; `kind: "css"` — HTML (`html`) берілген, оқушы CSS жазады. Тексеру ережелері:

```js
check: { rules: [
  { sel: "h1", count: 1, text: "Сәлем", label: "Бір h1 бар" },   // sel, min, max, count, text, attr, style, not
  { sel: ".box", style: { paddingTop: "20px" }, label: "padding 20px" },
], fn: (doc, win, code) => [{ label: "...", ok: true }] }
```

Ескерту: `border-width` сияқты қасиеттерді салыстырғанда функция қолдан: `{ borderTopWidth: (v) => v === "4px" }`.

## Қателерді қазақша түсіндіру
Python және JavaScript қателері қазақша түсіндіріледі: не болды, қай жолда (код жолы көрсетіледі) және 💡 қалай түзетуге болады (жақша/тырнақша тепе-теңдігі, `=` және `==`, қисық тырнақша, атау қателері мен ұсыныстар, индекс, кілт т.б.).

## Көрнекілік және баптаулар
- **⚙ Баптаулар** (жоғарғы жолақта): жарық / қараңғы / авто көрініс, мәтін өлшемі (A− … A++), дыбысты қосу/өшіру. Таңдау құрылғыда сақталады (`js/settings.js`).
- **Дыбыстар** файлсыз, WebAudio арқылы: робот қадамы, бұрылыс, жұлдыз, соғылу, жеңіс, қате.
- **Робот алаңы:** жүрген із, жұлдыз алынғанда ұшқын, секіріс анимациясы.
- **Жад панелі:** жаңа қорап «түсіп келеді», өзгерген мәннің ескісі сызылып көрінеді, тізімде өзгерген/жаңа ұяшық жарқырайды, `for`/`while` жолында айналым санауышы тұрады.
- **🎬 Алгоритм көрінісі** (`#/algo`, `js/algo.js`): көпіршік, таңдау, енгізу сұрыптауы, сызықтық және бинарлық іздеу, `fib` рекурсия ағашы. Қадамдап өту, артқа қайту, жылдамдық, өз сандарыңды енгізу, Python коды мен қазіргі жолдың белгіленуі.

## 🐞 Қате тап
Python (12), JavaScript (8), HTML (3) және CSS (4) курстарының «Қосымша» бөлімінде ішінде қатесі бар дайын код тұрады: тырнақша, қос нүкте, шегініс, қате ат, `=` және `==`, `return` ұмыту, шексіз цикл, массив шегі және т.б. Оқушы қате хабарын (қазақша түсіндірмесімен) оқып, қатені түзетеді. Деңгейлер `js/courses/debug-content.js` файлында (`debug: true`), жетістіктерге «Қате аулаушы» және «Бас детектив» қосылды.

## 🎓 Сертификат
Курстың барлық негізгі тапсырмасын орындаған оқушы сертификат алады: курс бетінде құттықтау карточкасы, «Жетістіктер» бетінде «Сертификаттар» бөлімі шығады (`#/certificate/<курс>`). Аты-жөнін жазса, сурет (PNG) ретінде жүктеп алуға немесе басып шығаруға болады. Сурет браузерде салынады (`js/cert.js`), серверге ештеңе жіберілмейді.

## Сыныпқа дайын тапсырма беру
Мұғалім «＋ Дайын тапсырма» арқылы сайттағы кез келген деңгейді (Python, JS, HTML, CSS, қосымша және «Қате тап») бір басумен сыныпқа береді: шешім де, күтілетін нәтиже де жазудың қажеті жоқ. Оқушы оны өз курсында орындайды (құлыпталған тақырып болса да ашылады, `#/<курс>/play/<деңгей>/open`), ал мұғалім «Нәтижелер» бөлімінде әр оқушының жұлдызын көреді. Өз тапсырмаңды жазу жолы да бар («✍ Өз тапсырмам»), онда шешім коды міндетті емес: күтілетін нәтижені тікелей жаза аласың. Дерекқор: `class_levels` кестесі және `assign_level`, `remove_level`, `class_levels_list`, `level_results`, `my_levels` функциялары (`supabase/schema.sql`).

## Келесі лекция батырмасы
Тақырыптың соңғы тапсырмасы орындалғанда, келесі тақырыптың лекциясы бар болса, нәтиже терезесінде «📖 Келесі лекция →» басты батырмасы шығады (Python, JS, HTML, CSS). «Келесі тапсырма →» екінші ретті батырма болып қалады.
Тапсырмалар лекцияны оқымай ашылмайды: тақырыптың лекциясында «Оқыдым деп белгіле» басылғанша «🎮 Тапсырмаға өту» жасырын, тапсырмалар қойындысында тақырып құлыпта тұрады. Тақырып соңында келесі лекция оқылмаған болса, тек «📖 Келесі лекция →» көрсетіледі. (SW кэші `botakod-v4`.)
